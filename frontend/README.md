📖 Overview

ACCENT is an intelligent English learning platform designed to connect students, tutors, and administrators in a unified educational ecosystem.
The platform provides tools for course management, quizzes, learning recommendations, and event organization while ensuring efficient administration and user management.

The goal of ACCENT is to improve the learning experience through interactive learning, structured course management, and AI-driven recommendations.

This project was developed as part of an academic software engineering project at ESPRIT – School of Engineering.

🏗 Architecture

The platform follows a microservices architecture to ensure scalability and modularity.

Main architectural components:

API Gateway

Service Discovery

Microservices for each domain

Frontend applications

Centralized database management

Each module is developed as an independent service, allowing easier maintenance and scalability.
